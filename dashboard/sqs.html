Amazon SQS

Simple Queue Service — decouple and scale microservices using message queues.
Supports standard queues and FIFO queues with exactly-once processing.

Endpoint: http://localhost:4566  |  Region: us-east-1  |  Access Key: test

Queue Management

Create standard queue

aws sqs create-queue \ --queue-name my-queue \ --endpoint-url http://localhost:4566

Create FIFO queue

aws sqs create-queue \ --queue-name my-queue.fifo \ --attributes FifoQueue=true \ --endpoint-url http://localhost:4566

List queues

aws sqs list-queues \ --endpoint-url http://localhost:4566

Get queue URL

aws sqs get-queue-url \ --queue-name my-queue \ --endpoint-url http://localhost:4566

Get queue attributes

aws sqs get-queue-attributes \ --queue-url <queue-url> \ --attribute-names All \ --endpoint-url http://localhost:4566

Delete queue

aws sqs delete-queue \ --queue-url <queue-url> \ --endpoint-url http://localhost:4566

Messages

Send message

aws sqs send-message \ --queue-url <queue-url> \ --message-body "Hello from SQS" \ --endpoint-url http://localhost:4566

Receive message

aws sqs receive-message \ --queue-url <queue-url> \ --max-number-of-messages 10 \ --endpoint-url http://localhost:4566

Delete message

aws sqs delete-message \ --queue-url <queue-url> \ --receipt-handle <handle> \ --endpoint-url http://localhost:4566

Purge all messages

aws sqs purge-queue \ --queue-url <queue-url> \ --endpoint-url http://localhost:4566

Dead Letter Queue

Create DLQ

aws sqs create-queue \ --queue-name my-queue-dlq \ --endpoint-url http://localhost:4566

Attach DLQ to queue

aws sqs set-queue-attributes \ --queue-url <queue-url> \ --attributes '{ "RedrivePolicy": "{ \"deadLetterTargetArn\":\"<dlq-arn>\", \"maxReceiveCount\":\"3\"}" }' \ --endpoint-url http://localhost:4566
