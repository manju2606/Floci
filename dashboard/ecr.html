Repository Management

Create Repository

aws --endpoint-url http://localhost:4566 ecr create-repository --repository-name <repo-name> --region us-east-1click to copy

List Repositories

aws --endpoint-url http://localhost:4566 ecr describe-repositories --region us-east-1click to copy

Delete Repository

aws --endpoint-url http://localhost:4566 ecr delete-repository --repository-name <repo-name> --force --region us-east-1click to copy

Docker Login & Push

Authenticate Docker to ECR

aws --endpoint-url http://localhost:4566 ecr get-login-password --region us-east-1 | docker login --username AWS --password-stdin 000000000000.dkr.ecr.us-east-1.localhost:5100click to copy
LocalStack ECR registry listens on port 5100, not 4566. Always use 000000000000.dkr.ecr.us-east-1.localhost:5100 as the registry hostname.

Tag & Push Image

docker tag <local-image>:<tag> 000000000000.dkr.ecr.us-east-1.localhost:5100/<repo-name>:<tag>click to copy
docker push 000000000000.dkr.ecr.us-east-1.localhost:5100/<repo-name>:<tag>click to copy

Pull Image

docker pull 000000000000.dkr.ecr.us-east-1.localhost:5100/<repo-name>:<tag>click to copy

Image Management

List Images in a Repository

aws --endpoint-url http://localhost:4566 ecr list-images --repository-name <repo-name> --region us-east-1click to copy

Describe Images

aws --endpoint-url http://localhost:4566 ecr describe-images --repository-name <repo-name> --region us-east-1click to copy

Delete Image

aws --endpoint-url http://localhost:4566 ecr batch-delete-image --repository-name <repo-name> --image-ids imageTag=<tag> --region us-east-1click to copy

Set Tag Mutability

aws --endpoint-url http://localhost:4566 ecr put-image-tag-mutability --repository-name <repo-name> --image-tag-mutability IMMUTABLE --region us-east-1click to copy

Helm Chart Push

Push Helm Chart to ECR

helm package ./click to copy
helm push <chart-file>.tgz oci://000000000000.dkr.ecr.us-east-1.localhost:5100/<repo-name>click to copy
Make sure you are logged in to the registry first using helm registry login or the aws ecr get-login-password pipe above.
