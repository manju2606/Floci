Amazon EKS Commands

Elastic Kubernetes Service — manage clusters, node groups, IAM roles, and workloads.
Works with both real AWS and the local Floci emulator at localhost:4566.

⎈ Open K8s Dashboard
Local endpoint: http://localhost:4566  |  Set: export AWS_ENDPOINT_URL=http://localhost:4566

Cluster Management EKS

Tip: For local Floci use --endpoint-url http://localhost:4566 on every AWS CLI command.

Create Kind cluster (local)

Spin up a local Kubernetes cluster with Kind.

kind create cluster --name my-cluster

Describe EKS cluster

Show details of an EKS cluster via Floci.

aws eks describe-cluster \ --name my-cluster \ --endpoint-url http://localhost:4566

List clusters

List all EKS clusters in the region.

aws eks list-clusters \ --endpoint-url http://localhost:4566

Cluster info

Display addresses of control plane and services.

kubectl cluster-info

Context & Config

Switch to docker-desktop context

kubectl config use-context docker-desktop

Switch to floci-cluster context

kubectl config use-context kind-floci-cluster

List all contexts

kubectl config get-contexts

Show current context

kubectl config current-context

Switch context + list pods

Switch and immediately verify pods across all namespaces.

kubectl config use-context kind-floci-cluster && \ kubectl get pods -A -o wide

IAM Roles

Note: Set AWS_ENDPOINT_URL=http://localhost:4566 first to target Floci.

Create EKS IAM role

Create the service role EKS needs to manage resources.

aws iam create-role \ --role-name eks-role \ --assume-role-policy-document '{ "Version": "2012-10-17", "Statement": [{ "Effect": "Allow", "Principal": { "Service": "eks.amazonaws.com" }, "Action": "sts:AssumeRole" }] }' \ --endpoint-url http://localhost:4566

List IAM roles

aws iam list-roles \ --endpoint-url http://localhost:4566

Delete IAM role

aws iam delete-role \ --role-name eks-role \ --endpoint-url http://localhost:4566

Node Groups

List node groups

aws eks list-nodegroups \ --cluster-name my-cluster \ --endpoint-url http://localhost:4566

Create node group

Add a managed node group to a cluster.

aws eks create-nodegroup \ --cluster-name my-cluster \ --nodegroup-name my-nodes \ --subnets subnet-abc subnet-def \ --node-role arn:aws:iam::000000000000:role/eksNodeRole \ --scaling-config minSize=1,maxSize=3,desiredSize=2 \ --endpoint-url http://localhost:4566

Get nodes (kubectl)

kubectl get nodes

Describe a node

kubectl describe node <node-name>

Workloads

Create nginx deployment

kubectl create deployment nginx --image=nginx

Expose deployment

Expose as a NodePort service on port 80.

kubectl expose deployment nginx \ --type=NodePort --port=80

List services

kubectl get svc

Get all pods

kubectl get pods -A -o wide

Delete deployment

kubectl delete deployment nginx

Kubernetes Dashboard UI

Start kubectl proxy

Exposes the API server locally so the dashboard UI is reachable.

kubectl proxy

Open dashboard URL

After running kubectl proxy, open this in a browser.

http://localhost:8001/api/v1/namespaces/kubernetes-dashboard/services/https:kubernetes-dashboard:/proxy/
