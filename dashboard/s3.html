Bucket Operations

Create bucket

aws s3 mb s3://my-bucket \ --endpoint-url http://localhost:4566 \ --region us-east-1

List buckets

aws s3 ls \ --endpoint-url http://localhost:4566

List objects in bucket

aws s3 ls s3://my-bucket \ --endpoint-url http://localhost:4566

Delete bucket

aws s3 rb s3://my-bucket \ --force \ --endpoint-url http://localhost:4566

Object Operations

Upload file

aws s3 cp ./file.txt s3://my-bucket/ \ --endpoint-url http://localhost:4566

Download file

aws s3 cp s3://my-bucket/file.txt ./ \ --endpoint-url http://localhost:4566

Sync folder to bucket

aws s3 sync ./my-folder s3://my-bucket \ --endpoint-url http://localhost:4566

Delete object

aws s3 rm s3://my-bucket/file.txt \ --endpoint-url http://localhost:4566

Generate presigned URL

aws s3 presign s3://my-bucket/file.txt \ --expires-in 3600 \ --endpoint-url http://localhost:4566

Copy between buckets

aws s3 cp s3://src-bucket/file.txt \ s3://dst-bucket/file.txt \ --endpoint-url http://localhost:4566
