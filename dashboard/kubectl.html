kubectl Commands

Quick reference for managing Kubernetes clusters, pods, deployments, and services.
Click any command to copy it to the clipboard.

Context: kubectl config current-context  |  Switch: kubectl config use-context <name>  |  Cluster: kubectl cluster-info

🌐 Context & Cluster

List all contexts

kubectl config get-contexts

Switch context

kubectl config use-context <context-name>

Current context

kubectl config current-context

Cluster info

kubectl cluster-info

API server version

kubectl version --short

Available API resources

kubectl api-resources

📄 Nodes

List all nodes

kubectl get nodes

Node details (wide)

kubectl get nodes -o wide

Describe a node

kubectl describe node <node-name>

Node resource usage

kubectl top nodes

Drain node (maintenance)

Evicts all pods before maintenance.

kubectl drain <node-name> \ --ignore-daemonsets \ --delete-emptydir-data

Uncordon node (restore)

kubectl uncordon <node-name>

📁 Namespaces

List namespaces

kubectl get namespaces

Create namespace

kubectl create namespace <name>

Set default namespace

kubectl config set-context --current \ --namespace=<name>

Delete namespace

Deletes all resources inside it.

kubectl delete namespace <name>

📦 Pods

Add -n <namespace> to scope to a namespace, or -A / --all-namespaces for all namespaces.

List pods

kubectl get pods

List pods (all namespaces)

kubectl get pods -A

Pod details (wide — shows node & IP)

kubectl get pods -o wide

Watch pod status live

kubectl get pods -w

Describe pod

kubectl describe pod <pod-name>

Pod logs

kubectl logs <pod-name>

Follow pod logs

kubectl logs -f <pod-name>

Logs — previous crashed container

kubectl logs <pod-name> --previous

Exec into pod shell

kubectl exec -it <pod-name> -- /bin/sh

Run a one-off pod

kubectl run debug --image=busybox \ --restart=Never --rm -it -- sh

Resource usage per pod

kubectl top pods

Delete pod

kubectl delete pod <pod-name>

Force delete stuck pod

kubectl delete pod <pod-name> \ --grace-period=0 --force

⚙ Deployments

List deployments

kubectl get deployments

Create deployment

kubectl create deployment <name> \ --image=<image> --replicas=2

Scale deployment

kubectl scale deployment <name> \ --replicas=3

Update image (rolling)

kubectl set image deployment/<name> \ <container>=<new-image>:<tag>

Rollout status

kubectl rollout status deployment/<name>

Rollout history

kubectl rollout history deployment/<name>

Rollback deployment

kubectl rollout undo deployment/<name>

Restart all pods

kubectl rollout restart deployment/<name>

Delete deployment

kubectl delete deployment <name>

🌐 Services

List services

kubectl get services

Expose deployment as service

kubectl expose deployment <name> \ --port=80 --type=ClusterIP

Port-forward to local machine

kubectl port-forward svc/<name> \ 8080:80

Port-forward to pod

kubectl port-forward pod/<pod-name> \ 8080:80

Describe service

kubectl describe svc <name>

Delete service

kubectl delete svc <name>

🔒 ConfigMaps & Secrets

List ConfigMaps

kubectl get configmaps

Create ConfigMap from file

kubectl create configmap <name> \ --from-file=config.properties

Create ConfigMap from literal

kubectl create configmap <name> \ --from-literal=key=value

List Secrets

kubectl get secrets

Create Secret (generic)

kubectl create secret generic <name> \ --from-literal=password=mypass

Decode Secret value

kubectl get secret <name> \ -o jsonpath='{.data.password}' | base64 -d

📄 Apply & Manage

Apply manifest

kubectl apply -f <file.yaml>

Apply directory of manifests

kubectl apply -f ./k8s/

Dry-run (validate only)

kubectl apply -f <file.yaml> \ --dry-run=client

Get resource as YAML

kubectl get deployment <name> -o yaml

Edit resource live

kubectl edit deployment <name>

Patch resource

kubectl patch deployment <name> \ -p '{"spec":{"replicas":3}}'

Delete by manifest

kubectl delete -f <file.yaml>

Label a resource

kubectl label pod <pod-name> env=prod

Filter by label

kubectl get pods -l app=<name>

🚀 Kind Clusters (local)

Create cluster

kind create cluster --name <name>

Create from config file

kind create cluster \ --config kind-cluster.yaml

List clusters

kind get clusters

Load local image into cluster

kind load docker-image <image>:<tag> \ --name <cluster-name>

Get kubeconfig

kind get kubeconfig --name <name>

Delete cluster

kind delete cluster --name <name>
