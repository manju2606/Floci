How to Connect
1
Start port-forwards
Run this from the Floci project root in a dedicated PowerShell window. Keep it open while working — port-forwards stop when the window closes.
.\retail-portforward.ps1click to copy
2
Connect via Adminer (MySQL / PostgreSQL)
Click Open Adminer on the DB card above — the link pre-fills the server, username and database automatically. Enter password kalyandb101 and click Login.

Direct links:  Catalog MySQL  •  Orders PostgreSQL
3
Connect via CLI
Use 127.0.0.1 and the port-forward port (e.g. 33306, 36379) directly from any local CLI tool. Click any CLI command above to copy it.
4
RabbitMQ management UI
Browse queues, exchanges and bindings at http://localhost:45672 (guest / guest).
