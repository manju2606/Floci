🛒 Retail Store Databases

In-cluster databases deployed by the retail-store sample app — exposed via kubectl port-forward
Port-forwards required. These databases run inside the KinD cluster as ClusterIP services. Run .\retail-portforward.ps1 from the Floci project root to expose them on localhost before connecting.

How to Connect
1
Start port-forwards
Run this from the Floci project root in a PowerShell window. Keep it open while working.
.\retail-portforward.ps1click to copy
2
Connect via Adminer (MySQL / PostgreSQL)
Click Open in Adminer on the DB card above — it pre-fills the server, username and database automatically. Enter the password (kalyandb101) and click Login.

Direct links:  Catalog MySQL  •  Orders PostgreSQL
3
Connect via CLI from Windows host
Use 127.0.0.1 and the port-forward port (e.g. 33306, 36379) directly from any local CLI tool.
4
RabbitMQ management UI
Browse queues, exchanges and bindings at http://localhost:45672 (guest / guest).
