Security Group Commands

Create security group

aws ec2 create-security-group \ --group-name my-sg \ --description "My security group" \ --endpoint-url http://localhost:4566

Add inbound rule (SSH)

aws ec2 authorize-security-group-ingress \ --group-id <sg-id> \ --protocol tcp --port 22 \ --cidr 0.0.0.0/0 \ --endpoint-url http://localhost:4566

Add inbound rule (HTTP)

aws ec2 authorize-security-group-ingress \ --group-id <sg-id> \ --protocol tcp --port 80 \ --cidr 0.0.0.0/0 \ --endpoint-url http://localhost:4566

Delete security group

aws ec2 delete-security-group \ --group-id <sg-id> \ --endpoint-url http://localhost:4566

Key Pair Commands

Create key pair

aws ec2 create-key-pair \ --key-name my-key \ --query 'KeyMaterial' \ --output text > my-key.pem \ --endpoint-url http://localhost:4566

List key pairs

aws ec2 describe-key-pairs \ --endpoint-url http://localhost:4566

Delete key pair

aws ec2 delete-key-pair \ --key-name my-key \ --endpoint-url http://localhost:4566

Import existing key

aws ec2 import-key-pair \ --key-name my-key \ --public-key-material fileb://~/.ssh/id_rsa.pub \ --endpoint-url http://localhost:4566

Volume Commands

Create volume

aws ec2 create-volume \ --size 20 --volume-type gp3 \ --availability-zone us-east-1a \ --endpoint-url http://localhost:4566

Attach volume

aws ec2 attach-volume \ --volume-id <vol-id> \ --instance-id <instance-id> \ --device /dev/xvdf \ --endpoint-url http://localhost:4566

Create snapshot

aws ec2 create-snapshot \ --volume-id <vol-id> \ --description "My snapshot" \ --endpoint-url http://localhost:4566

Delete volume

aws ec2 delete-volume \ --volume-id <vol-id> \ --endpoint-url http://localhost:4566

VPC Commands

Create VPC

aws ec2 create-vpc \ --cidr-block 10.0.0.0/16 \ --endpoint-url http://localhost:4566

Create subnet

aws ec2 create-subnet \ --vpc-id <vpc-id> \ --cidr-block 10.0.1.0/24 \ --availability-zone us-east-1a \ --endpoint-url http://localhost:4566

Create internet gateway

aws ec2 create-internet-gateway \ --endpoint-url http://localhost:4566

Attach IGW to VPC

aws ec2 attach-internet-gateway \ --internet-gateway-id <igw-id> \ --vpc-id <vpc-id> \ --endpoint-url http://localhost:4566

Launch Instances

Run instance (Amazon Linux 2)

aws ec2 run-instances \ --image-id ami-0abcdef1234567890 \ --instance-type t2.micro \ --key-name my-key \ --security-group-ids <sg-id> \ --count 1 \ --endpoint-url http://localhost:4566

Run instance with user data

aws ec2 run-instances \ --image-id ami-0abcdef1234567890 \ --instance-type t2.micro \ --user-data file://init.sh \ --endpoint-url http://localhost:4566

Run multiple instances

aws ec2 run-instances \ --image-id ami-0abcdef1234567890 \ --instance-type t3.small \ --count 3 \ --endpoint-url http://localhost:4566

Describe instances

aws ec2 describe-instances \ --output table \ --endpoint-url http://localhost:4566

Instance Lifecycle

Start instance

aws ec2 start-instances \ --instance-ids <instance-id> \ --endpoint-url http://localhost:4566

Stop instance

aws ec2 stop-instances \ --instance-ids <instance-id> \ --endpoint-url http://localhost:4566

Reboot instance

aws ec2 reboot-instances \ --instance-ids <instance-id> \ --endpoint-url http://localhost:4566

Terminate instance

aws ec2 terminate-instances \ --instance-ids <instance-id> \ --endpoint-url http://localhost:4566

AMI Management

Create AMI from instance

aws ec2 create-image \ --instance-id <instance-id> \ --name "My AMI" \ --no-reboot \ --endpoint-url http://localhost:4566

Describe AMIs (owned)

aws ec2 describe-images \ --owners self \ --endpoint-url http://localhost:4566

Deregister AMI

aws ec2 deregister-image \ --image-id <ami-id> \ --endpoint-url http://localhost:4566

Tag a resource

aws ec2 create-tags \ --resources <resource-id> \ --tags Key=Name,Value=my-instance \ --endpoint-url http://localhost:4566
